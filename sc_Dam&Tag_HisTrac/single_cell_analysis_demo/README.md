For the demo dataset, peaks were selected from the union of replicate peak calls
based on fragment support in the selected demo cells. The same downsampled peak
set is provided for both replicates to keep the demo small. This demo dataset is
intended only to test the object-construction workflow and is not intended for
biological interpretation.

This demo uses a downsampled nanoscope output from the Day7R Dam-Leo1 scHisTrac-seq
example. It contains approximately 500 paired single cells across two biological
replicates and 5,000 selected peaks per modality.
The downsampled nanoscope output was prepared by
01_choose_demo_cells.R
02_make_demo_nanoscope_subset.sh

From the downsampled nanoscope output, Seurat object is prepared by demo_Seurat_object_preparation.R
and further analysed by demo_clustering_geneactivity_analysis.R

Expected output:
- combined.obj.ls.demo.rds
- combined.obj.ls_analysis.demo.rds
- QC plots generated by plotCounts(), venn diagram, DepthCorMulMod(), ElbowPlot(), DimPlot(), FeaturePlot()
- two Seurat objects corresponding to the Dam and H3K27ac modalities

Expected runtime:
Approximately 5–20 minutes on a standard desktop or laptop, depending on disk
speed and available memory.

Hardware:
No non-standard hardware is required for the demo. Full-scale analysis of the
complete dataset requires substantially more memory/storage and is recommended
on a workstation or HPC.
