# Single-cell HisTrac-seq demo analysis

This directory contains a small demonstration dataset and example scripts for the single-cell Dam&Tag / scHisTrac-seq analysis workflow used in:

**Whole-genome single-cell multimodal molecular recording reveals cell identity transitions**

The demo is based on a downsampled Day7R Dam-Leo1 scHisTrac-seq example. It is intended to demonstrate how nanoscope-derived single-cell chromatin outputs can be converted into Seurat/Signac objects and processed through a minimal downstream workflow.

This demo dataset is provided for software testing and workflow demonstration. It is not intended for biological interpretation or for reproducing the full results of the manuscript.

---

## Overview of the demo workflow

The demo covers two main steps:

1. **Seurat object preparation from nanoscope outputs**
   Script: `demo_Seurat_object_preparation.R`

   This script reads downsampled nanoscope-style outputs, including peak calls, fragment files and cell metadata. It then constructs Signac/Seurat chromatin assays, applies basic cell filtering, keeps cells that passed QC in both Dam and H3K27ac modalities, merges biological replicates and saves the resulting object list.

2. **Minimal clustering and gene-activity analysis**
   Script: `demo_clustering_geneactivity_analysis.R`

   This script loads the prepared Seurat object list, performs TF-IDF normalization, feature selection, LSI, UMAP embedding, clustering and gene-activity calculation for the Dam and H3K27ac modalities.

## Demo dataset

The demo dataset was generated by downsampling a Day7R Dam-Leo1 scHisTrac-seq dataset.

It contains approximately:

* 500 paired single cells across two biological replicates
* two modalities:

  * `Day7R.Dam_bb`, representing the historical Dam modality
  * `Day7R.K27ac_aa`, representing the present H3K27ac modality
* 5,000 selected peaks per modality

For the demo dataset, peaks were selected from the union of replicate peak calls based on fragment support in the selected demo cells. The same downsampled peak set is provided for both replicates to keep the demo small and reproducible.

Because this is a strongly downsampled dataset, the output should be used only to check that the workflow runs and produces expected object structures and diagnostic plots. It should not be used to draw biological conclusions.

## Scripts

### `01_choose_demo_cells.R`

Selects a small set of paired cells from the full nanoscope output. Cells are selected from barcodes present in both Dam and H3K27ac modalities within each replicate.

This script is only needed if you want to regenerate the demo dataset from the full nanoscope output.

Example usage:

```bash
Rscript 01_choose_demo_cells.R /path/to/full/Day7R_MERGED Day7R_MERGED_demo 500 42
```

Arguments:

```text
1. Path to the full nanoscope output directory
2. Output directory for the demo dataset
3. Approximate number of cells to select
4. Random seed
```

### `02_make_demo_nanoscope_subset.sh`

Creates a downsampled nanoscope-style folder from the selected cells. It filters fragment files, selects supported peaks, writes downsampled `broadPeak` and `peaks.bed` files, and creates indexed `fragments.tsv.gz` files.

This script is only needed if you want to regenerate the demo dataset from the full nanoscope output.

Example usage:

```bash
bash 02_make_demo_nanoscope_subset.sh /path/to/full/Day7R_MERGED Day7R_MERGED_demo 5000
```

Arguments:

```text
1. Path to the full nanoscope output directory
2. Output directory for the demo dataset
3. Number of peaks to retain per modality
```

This script requires command-line tools such as `bedtools`, `bgzip` and `tabix`.

### `demo_Seurat_object_preparation.R`

Builds Seurat/Signac objects from the downsampled nanoscope output.

Main operations:

* reads peak calls from `peaks/macs_broad/*_peaks.broadPeak`
* merges peak sets across biological replicates for each modality
* reads `cell_picking/metadata.csv`
* keeps Cell Ranger-called cells using `is__cell_barcode`
* creates fragment objects from `fragments.tsv.gz`
* quantifies peak counts with `FeatureMatrix`
* creates chromatin assays and Seurat objects
* applies simple QC based on `logUMI` and `peak_ratio_MB`
* keeps cells passing QC in both Dam and H3K27ac modalities
* merges replicate-level objects
* saves `combined.obj.ls.demo.rds`

Before running, edit the following paths in the script:

```r
repodir <- "/path/to/your/nanoscope/"
setwd("path/to/your/Day7R_MERGED_demo/")
```

Run:

```bash
Rscript demo_Seurat_object_preparation.R
```

Expected output:

```text
Day7R_MERGED_demo/combined.obj.ls.demo.rds
```

### `demo_clustering_geneactivity_analysis.R`

Runs a minimal downstream analysis from the prepared Seurat object list.

Main operations:

* loads `combined.obj.ls.demo.rds`
* performs TF-IDF normalization
* selects top features
* performs LSI
* inspects depth correlation and elbow plots
* runs UMAP and clustering separately for each modality
* adds gene annotations from `EnsDb.Mmusculus.v79`
* computes gene activity assays:

  * `RNA.K27ac`
  * `RNA.Dam`
* saves `combined.obj.ls_analysis.demo.rds`

Before running, edit the following paths in the script:

```r
repodir <- "/path/to/your/nanoscope/"
setwd("path/to/your/Day7R_MERGED_demo/")
```

Run:

```bash
Rscript demo_clustering_geneactivity_analysis.R
```

Expected output:

```text
Day7R_MERGED_demo/combined.obj.ls_analysis.demo.rds
```

A precomputed version of this file is also provided in:

```text
Seurat_object/combined.obj.ls_analysis.demo.rds
```

The demo was designed for an R/Signac/Seurat workflow.

Recommended software environment:

```text
R >= 4.4
Seurat >= 5
Signac >= 1.14
GenomicRanges
EnsDb.Mmusculus.v79
ggplot2
ggpubr
gghalves
ComplexUpset
regioneR
scales
ggVennDiagram
harmony
biovizBase
future
stringr
```

For regenerating the downsampled nanoscope output from full data, the following command-line tools are also required:

```text
bedtools
bgzip
tabix
awk
sort
zcat
```

The scripts also source helper functions from a local clone of the nanoscope repository:

```r
repodir <- "/path/to/your/nanoscope/"
source(paste0(repodir, "scripts/functions_scCT2.R"))
```

Please update `repodir` to the location of your local nanoscope clone before running the scripts.

## Quick start

From the repository root:

```bash
cd 'sc_Dam&Tag_HisTrac/single_cell_analysis_demo'
```

Edit paths in both R scripts:

```r
repodir <- "/path/to/your/nanoscope/"
setwd("path/to/your/histrac_1/sc_Dam&Tag_HisTrac/single_cell_analysis_demo/Day7R_MERGED_demo/")
```

Then run:

```bash
Rscript demo_Seurat_object_preparation.R
Rscript demo_clustering_geneactivity_analysis.R
```

The `&` character in the directory name should be quoted or escaped in bash. For example:

```bash
cd 'sc_Dam&Tag_HisTrac/single_cell_analysis_demo'
```

or:

```bash
cd sc_Dam\&Tag_HisTrac/single_cell_analysis_demo
```

## Expected output

The object-preparation step should generate:

```text
combined.obj.ls.demo.rds
```

The clustering and gene-activity step should generate:

```text
combined.obj.ls_analysis.demo.rds
```

The final R object is a list containing two Seurat objects:

```text
combined.obj.ls$Day7R.Dam_bb
combined.obj.ls$Day7R.K27ac_aa
```

These objects contain the `peaks` assay. After running `demo_clustering_geneactivity_analysis.R`, they also contain gene-activity assays:


```text
plotPassed()

plotCounts()
commonCellHistonMarks()

ElbowPlot()
DimPlot()
FeaturePlot()
```

## Runtime and hardware

Expected runtime for the downsampled demo:

```text
Seurat object preparation: approximately 5–20 minutes
Clustering and gene-activity analysis: approximately 5–20 minutes
```

Runtime depends on disk speed, memory and CPU availability.

No non-standard hardware is required for the demo. A standard workstation or laptop with sufficient memory should be adequate.

The full-scale analysis of the complete single-cell HisTrac-seq dataset requires substantially more memory and storage and is recommended on a workstation or HPC system.

## Known warnings

During TF-IDF normalization or feature selection, warnings such as the following may appear:

```text
Some features contain 0 total counts
```

This can occur after the QC and paired-cell filtering steps in the downsampled demo dataset. For the purpose of checking that the workflow runs and produces the expected objects, this warning is usually safe to ignore.

---

## Relationship to the full manuscript analysis

This demo implements a simplified version of the single-cell Dam&Tag / scHisTrac-seq processing workflow.

The full manuscript analysis includes additional steps, larger datasets, additional biological conditions, full-scale quality control, cell-type annotation, identity-transition analysis, gene/peak differential analysis, perturbation analysis and statistical modeling. Those analyses are not reproduced by this small demo dataset.

Full sequencing data are deposited in ArrayExpress under the accessions described in the manuscript. The demo dataset in this repository is provided only as a lightweight example for reviewers and users to test the computational workflow.
