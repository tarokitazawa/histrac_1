# Single-cell downstream analysis

This directory contains the core **Seurat/Signac downstream analysis workflow** used for scDam&Tag and scHisTrac-seq.

The workflow starts from modality-specific single-cell outputs generated by the modified **Nanoscope** preprocessing pipeline and proceeds through Seurat object construction, replicate merging, dimensionality reduction, clustering, and gene activity analysis.

The analysis is based on and adapted from the Nanoscope [“Analysis using peaks” vignette](https://fansalon.github.io/vignette_single-cell-nanoCT.html).

---

## Workflow overview

### 1. Nanoscope preprocessing

Raw 10x Genomics FASTQ files are first processed using the modified Nanoscope workflow described in:

[`../nanoscope_implementation/`](../nanoscope_implementation/)

This step performs sample and modality demultiplexing, alignment, cell calling, and peak calling and generates separate outputs for the **Dam** and **H3K27ac** modalities.

The scripts in this directory therefore assume that Nanoscope preprocessing and modality demultiplexing have already been completed.

---

### 2. Conversion of Nanoscope output for replicate merging

Before downstream analysis, the Nanoscope output directories are reorganized into a consistent structure that allows biological replicates, experimental stages, or treatment conditions to be processed and merged programmatically.

The required directory structure and examples are described in:

[`Conversion_of_Nanoscope_Output_for_Replicate_Merging.md`](Conversion_of_Nanoscope_Output_for_Replicate_Merging.md)

This conversion is a prerequisite for the example workflows below.

---

### 3. Seurat object preparation

[`Seurat_object_preparation.R`](Seurat_object_preparation.R) converts the reorganized Nanoscope outputs into Seurat/Signac objects.

The script performs the following main steps:

- imports modality-specific MACS2 peak sets generated by Nanoscope;
- merges peak sets across biological replicates within each modality;
- loads Nanoscope/Cell Ranger cell-level metadata;
- applies cell filtering and additional QC;
- creates Signac fragment objects and peak-by-cell feature matrices;
- constructs Seurat chromatin-assay objects for each replicate and modality;
- retains cells represented in both the Dam and H3K27ac modalities; and
- merges biological replicates separately for each modality.

The resulting list of merged Seurat objects is saved as:

```text
combined.obj.ls.rds
```

The current script uses **Dam-Leo1/H3K27ac Day7R (HisTrac)** with two biological replicates as an example. Sample names, numbers of replicates, and modalities should be adapted for other experiments.

---

### 4. Clustering and gene activity analysis

[`clustering_geneactivity_analysis.R`](clustering_geneactivity_analysis.R) performs downstream analysis of the merged objects generated above.

The main analysis steps include:

- TF-IDF normalization;
- feature selection;
- latent semantic indexing (LSI);
- inspection of sequencing-depth correlations and LSI elbow structure;
- UMAP embedding;
- graph construction and clustering for each modality;
- transfer and comparison of cluster annotations between matched Dam and H3K27ac cells;
- addition of gene annotations;
- calculation of gene activity scores from the H3K27ac and Dam modalities; and
- visualization of corresponding cells across present-state and historical modalities.

The analyzed objects are saved as:

```text
combined.obj.ls_analysis.rds
```

The LSI dimensions and clustering parameters shown in the script correspond to the example dataset and should be evaluated for individual datasets using the depth-correlation and elbow diagnostics.

## Custom helper functions

Several functions used by these scripts are adapted from the original Nanoscope single-cell analysis helpers.

The modified helper script used in this repository is:

[`../helper_functions/functions_scCT2.R`](../helper_functions/functions_scCT2.R)

`functions_scCT2.R` retains the core Nanoscope helper functions while adding modifications used in the scDam&Tag/scHisTrac-seq workflow, particularly for QC visualization and visualization of matched cells between modalities.

Keeping this helper script within the repository ensures that the downstream analyses can be reproduced without modifying the local Nanoscope installation.
